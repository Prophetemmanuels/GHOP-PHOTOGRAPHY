# GHOP FRIENDLY PREDICTOR

Pattern-based Aviator analysis tool inspired by Bolabet gameplay behaviour.

## Features
- Multiplier history tracking
- Expected multiplier range
- Volatility & bias detection
- 2x ABOVE / BELOW behaviour chart
- Decision assistance (bet or wait)
- PWA installable

## Disclaimer
This app does NOT predict exact Aviator outcomes.
It provides statistical guidance only.
